Actual local verification

Windows, Python 3.14.7, Streamlit 1.66.0: 27 scanner/CLI tests and two Streamlit interaction tests passed. Python compilation, JavaScript syntax and dependency checks passed. Local static HTTP and Streamlit health endpoints returned HTTP 200.

Microsoft Edge checks covered both scenarios, filtering, export contents, internal anchors, six viewport widths (320?1440 pixels), and absence of JavaScript errors or external demo requests. Screenshots and detailed limitations accompany the repository.
