Understand what’s being checked.

CyberShield reviews HTTP response configuration using a small Python engine. The local dashboard requires confirmation that you own the target or have explicit permission to audit it.

Run the local Python auditor ↗
  1. 01

    Confirm scope

    Validate an authorized public URL. Block private addresses and unrelated redirect hosts.

  2. 02

    Observe the response

    Read headers with verified TLS, up to three redirects and one optional Origin probe. No crawling or login attempts.

  3. 03

    Review and report

    Classify configuration observations and export JSON or HTML. Cookie values and response bodies are never retained.

Scoring & limitations

Start at 100; subtract 17 per high, 10 per medium and 5 per low warning, with a floor of 0. Grades: A ≥90, B ≥75, C ≥60, D ≥40, F <40. Informational observations do not affect the score.

A single response cannot represent an entire website. CSP presence does not establish policy quality. CORS reflection does not prove sensitive data exposure. HTTPS checks do not audit cipher suites. DNS checks are best effort, so keep the Python dashboard local. This is not a penetration test or security certification.
